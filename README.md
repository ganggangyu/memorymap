# Our Romantic Journey - 我们的浪漫之旅

这是一个交互式Web应用程序，旨在以美丽而富有情感的方式可视化和记录一段浪漫旅程中的珍贵时刻和地点。用户可以在动态地图上看到他们的足迹，并在时间轴上回顾每一个重要的记忆。

## ✨ 主要功能

- **交互式地图 (Interactive Map)**: 所有记忆点都在世界地图上进行标记。用户可以通过点击地图上的标记来探索相关的记忆。多个在同一地点的记忆会被智能地组合在一起。
- **动态时间轴 (Dynamic Timeline)**: 以时间顺序垂直展示所有记忆。时间轴支持滚动、搜索，并能高亮显示当前选中的事件。
- **详细记忆视图 (Detailed Memory View)**: 点击时间轴或地图标记后，会展示一个包含长篇故事、多张照片幻灯片和背景音乐的详细面板。
- **记忆管理 (Memory Management)**: 用户可以轻松添加、编辑和删除自己的记忆。表单支持图片上传（带压缩）、音频文件上传和地理位置选择。
- **数据持久化 (Data Persistence)**:
  - **本地存储**: 所有记忆都会自动保存在浏览器的本地存储中，以便下次访问时保留。
  - **导入/导出**: 用户可以将他们的整个旅程（包括所有记忆和媒体文件）导出为一个 `.zip` 文件进行备份，也可以从备份文件中恢复他们的旅程。
- **成就系统 (Achievement System)**: 通过完成特定任务（如创建第一个记忆）来解锁成就，为记录回忆增添了游戏化的乐趣。
- **爱心发射器 (Heart Emitter)**: 在地图界面有一个可爱的爱心按钮，点击后会迸发出一簇美丽的爱心动画，为应用增添了一丝甜蜜和趣味。
